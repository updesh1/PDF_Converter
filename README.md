# 📄 PDF Converter Tool

A simple and user-friendly PDF Converter built with **Python** and **Streamlit**. It allows users to convert, manage, and secure PDF files directly from their browser without installing any software.

## 🌐 Live Demo

👉 https://pdf-converter-ps6p.onrender.com/

---

## ✨ Features

- 📄 DOCX to PDF
- 🖼️ Image to PDF
- 📝 Text to PDF
- 🖼️ PDF to Images
- 📚 Merge Multiple PDFs
- ✂️ Split PDF
- 🗜️ Compress PDF
- 🔄 Rotate PDF
- 🔒 Password Protect PDF
- 🔓 Unlock PDF
- ℹ️ View PDF Information

---

## 🚀 How to Use

1. Open the website.
2. Select the required tool from the sidebar.
3. Upload your file(s).
4. Click the corresponding action button.
5. Wait for the conversion to complete.
6. Download the processed file.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/updesh1/PDF_Converter.git
```

Go to the project folder:

```bash
cd PDF_Converter
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
